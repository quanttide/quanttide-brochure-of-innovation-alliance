# 在哪里进行

所有选拔活动都在线上进行，主要发生在三个地方：官网、GitHub 和飞书。三者分别承担公开入口、作品记录和组织协作，不依赖线下地点。

## 三个主要线上空间

### 官网

对外公开层：候选人从这里了解选拔方式，进入项目、游戏等具体入口。官网不需要组织权限，任何人都可以访问。

创始人渠道的第一个练手项目[《滁州夜市·串串摊》](https://tycoon.game.quanttide.com/)托管于官网的子域名。

### GitHub

公开的作品层：源码、文档、Issue 和提交记录都在这里，承载可追溯的项目与交付。GitHub 同样公开，但承载的是项目成果本身，而非介绍与入口。

创始人渠道的游戏源码在 [quanttide/qtgame-tycoon](https://github.com/quanttide/qtgame-tycoon)。

### 飞书

组织协作层：群、群邮件、实训基地与公司的日常协作都在飞书进行，覆盖沟通、培养与考核。飞书需要邀请或权限方可访问，不属于公开空间。

## 各渠道的线上落点

| **渠道** | **入口** | **主要落点** |
|:--|:--|:--|
| 默认招聘 | 官网、群邮件 | 飞书群、实训基地 |
| 众包 | 众包网站 | GitHub、飞书 |
| 课堂 | 官网、飞书 | GitHub 资料、实训基地 |
| SVIP | 飞书 | 实训基地部门 |
| 创始人 | 官网游戏站、GitHub | 飞书群、实训基地 |

三者不是互相替代的关系：官网负责引导候选人进入，GitHub 留存可追溯的项目成果，飞书完成组织内的培养与考核。
